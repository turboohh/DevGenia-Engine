# DevGenia Studio

DevGenia combines a Java game editor, a Windows Player and a creator platform.

**[Download DevGenia Studio 0.14.8](https://github.com/turboohh/DevGenia-Engine/releases/download/v0.14.8/DevGeniaSetup-0.14.8.exe)** · [All releases](https://github.com/turboohh/DevGenia-Engine/releases) · [DevGenia website](https://devgenia.com)

The Windows installer includes Studio, Player and the required Java runtime.
Installers belong to GitHub Releases, so cloning this repository does not download
every historical executable.

## Latest update: 0.14.8

- A color wheel with brightness, HEX/RGB input and current/new previews.
- Click a literal `new Color(...)` expression in the script editor to edit its color.
- Edit compatible properties across selected Parts and other instances, with one-step Undo/Redo.
- Efficient bulk editing and fixes for unintended numeric rounding during inspector refreshes.

## Release archive

This archive contains the 27 preserved Studio distributions (installers and an early portable build) available on

checksums. The existing repository history has been preserved.

Private operational details have been omitted from selected historical notes;
those edited archive copies are labeled. Installer bytes and original signed
manifests remain unchanged. Historical notes describe each release at the time,
not guarantees about the current platform.

The `v*` archive tags contain **release metadata, not reconstructed historical
source code**. GitHub's automatically generated “Source code” archives for these
tags are therefore not the application. Download the named installer asset
(or the explicitly labeled portable ZIP for the earliest version) instead.
Archival commits record today's import; they do not pretend to be the original
development commits.

## Historical availability

- Legacy/local archives are labeled as prereleases on GitHub. They may expect a
  local development server and are provided for historical reference only. Use
  the latest installer for current games; details are recorded in each release.
- **0.8.2 was withdrawn** after an audio identity regression, with a rollback to
  0.8.1. It is documented here rather than presented as a recommended download.
- **0.8.4 was a website/server update**; the desktop installer remained 0.8.3.
- Earlier installer verification fixtures are not product releases and are not
  distributed as Studio downloads.
- The original 0.5.0 product installer was not recovered. Its surviving installer
  verification fixture is not substituted for the original release.

## Checksums and original signatures

Every release has `SHA256SUMS`. From 0.11.0 onward the preserved signed manifest,
signature and public verification key are included as well. Their original
`devgenia.com` URLs have not been edited, because editing a signed manifest would
invalidate its signature. The manifests are archival evidence; this import does
not change the application's existing update server.

The release signature is separate from Windows publisher/Authenticode signing.
No private keys, account databases or local user state are included.

The older engine guides in this repository remain available as historical
documentation. For version-specific changes, use the release notes above.
